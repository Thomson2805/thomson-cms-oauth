# Thomson CMS OAuth Gateway

Upload all files to the root of the `thomson-cms-oauth` GitHub repository. Vercel will build this automatically; no local Node.js installation is required.

Required Vercel variables:
- `OAUTH_GITHUB_CLIENT_ID`
- `OAUTH_GITHUB_CLIENT_SECRET`
- `ADMIN_ORIGIN` = `https://thomson-saragih.vercel.app`

GitHub OAuth callback URL:
`https://thomson-cms-oauth-9wkz.vercel.app/callback`
